# 📊 Bank Analytics Excel Dashboard  

This repository contains an **Excel Dashboard Project** for analyzing **Bank Transactions** and **Loan Performance**.  
It is designed to help stakeholders gain insights into **debit/credit trends**, **customer activity**, and **loan performance metrics**.  

---

## 📂 Project Contents  
- **Excel Dashboard File:** `Excel Dashboard 3 project new.xlsx`  
- **Dashboards:**  
  1. **Bank Debit & Credit Dashboard**  
  2. **Bank Loan Analytics Dashboard**  

---

## 🔹 Dashboard 1: Bank Debit and Credit Analysis  

This dashboard provides insights into **transaction activities** (credits, debits, net balances, ratios, etc.).  

### ✅ Key KPIs:  
1. **Total Credit Amount** – Sum of all credits (deposits).  
2. **Total Debit Amount** – Sum of all debits (withdrawals).  
3. **Credit to Debit Ratio** – Ratio of credits vs debits.  
4. **Net Transaction Amount** – Credit minus Debit.  
5. **Account Activity Ratio** – Transactions vs account balance.  
6. **Transactions per Day/Week/Month** – Frequency of transactions.  
7. **Total Transaction Amount by Branch** – Compare performance of different branches.  

---

## 🔹 Dashboard 2: Bank Loan Analytics  

This dashboard tracks **loan disbursement, repayment, and portfolio quality** across branches and groups.  

### ✅ Key KPIs:  
1. **Total Loan Amount Funded** – Value of loans disbursed.  
2. **Total Loans** – Number of loans issued.  
3. **Total Collection** – Principal + Interest collected.  
4. **Total Interest** – Interest revenue from loans.  
5. **Branch-Wise Performance** – Loan revenue per branch.  
6. **State-Wise Loan** – Geographic loan distribution.  
7. **Religion-Wise Loan** – Loan distribution by demographics.  
8. **Product Group-Wise Loan** – Loan types (personal, auto, etc.).  
9. **Disbursement Trend** – Loan disbursement over time.  
10. **Grade-Wise Loan** – Credit grade analysis.  
11. **Default Loan Count** – Number of defaulted loans.  
12. **Delinquent Client Count** – Borrowers with missed payments.  
13. **Delinquent Loan Rate** – % of overdue loans.  
14. **Default Loan Rate** – Proportion of defaults in portfolio.  
15. **Loan Status-Wise Loan** – Status breakdown (active, closed, delinquent).  
16. **Age Group-Wise Loan** – Loan distribution by borrower age.  
17. **Loan Maturity** – Timeline until repayment.  
18. **No Verified Loans** – Loans without proper verification.
